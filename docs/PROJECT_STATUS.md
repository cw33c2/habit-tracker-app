# 專案狀態看板 (Project Status)

## 📌 產品摘要 (Product Vision)
**產品名稱**：極簡高效習慣清單 (Midnight Habit Tracker)
**核心理念**：極簡、無腦打卡、遊戲化圖表、無壓力。
**跨平台策略**：採用 **PWA (漸進式網頁應用程式)** 技術與 **RWD (響應式設計)**。只要寫一套程式碼，就能同時在「電腦版」與「手機版」完美呈現。使用者可直接將網頁「加入手機主畫面」，享受與原生 App 100% 相同的全螢幕體驗。

## 🎯 核心功能清單 (Features)
1. **自訂習慣清單**：自由新增、修改、刪除習慣標題與提醒時間。
2. **任務類型標籤 (Tags)**：常駐習慣、倒數挑戰、期間限定、一次性任務。
3. **打卡筆記與日誌**：打卡時彈出選填筆記，統計頁面展示日誌倒序時間軸。
4. **Google Sheets 雙向雲端自動同步**：背景靜默同步寫入 Google 試算表，支援跨裝置。
5. **PWA 系統推播通知與音效**：每日定時發送推播通知，可獨立開啟/關閉聲音。
6. **一鍵睡眠追蹤與起居圖表**：一鍵記錄「我要睡了 🌙 / 我起床了 ☀️」，自動計算睡眠時數與可視化圖表。
7. **成就徽章系統 (Badges)**：13 款解鎖徽章與連勝進度。
8. **深淺色主題切換**：極夜黑客 (Midnight Hacker) / 清爽淺色雙主題。
